# КлипМастер 1.0.0

Офлайн-видеоредактор для Android (Capacitor 8 + нативный движок на Media3 Transformer 1.8.0). Магазин: RuStore. appId `com.clipmaster.app`.

## Артефакты (`dist/`)
- `KlipMaster-1.0.0-debug.apk` — отладочная сборка
- `KlipMaster-1.0.0-release.apk` — подписанный release (ключ `release/clipmaster-release.jks`)
- `KlipMaster-1.0.0-release.aab` — подписанный bundle для загрузки в RuStore

## Функции (собрано; на реальном устройстве ещё не проверено — на сборочной машине нет эмулятора)
- Импорт нескольких видео (копия во внутреннюю память), таймлайн с миниатюрами
- Обрезка начала/конца, разрезание по плееру, дублирование, перестановка, удаление
- Скорость клипа 0.25×–3× (вместе со звуком; без звука — только видео)
- Переходы на каждый стык (≈0,8 с):
  - **с наложением клипов** (две видеодорожки + VideoCompositor): Наплыв (кроссфейд), Шторка ←/→ (новый клип надвигается поверх старого)
  - без наложения: Затемнение, Вспышка, Сдвиг ←/→, Наезд
- 12 фильтров на клип (Media3 HSL/Contrast/RgbMatrix): Яркий, Тёплый, Холодный, Ч/Б, Кино, Винтаж, Пастель, Драма, Закат, Сепия, Мята, Негатив
- Музыка: громкость трека и исходного звука (0–150%), старт трека, отключение оригинала, зацикливание
- Текст: 4 размера, стили (плашка/жирный/тонкий/акцент), 6 цветов, позиция
- Формат 16:9 (1280×720) / 9:16 (720×1280), экспорт MP4 H.264/AAC с прогрессом и отменой
- Сохранение в галерею Movies/KlipMaster (Android 10+; на 7–9 — Android/data/com.clipmaster.app/files/Movies)
- Автосохранение и восстановление проекта, кнопка «Новый»

## Ограничения
- Переходы и точные цвета фильтров видны только в экспортированном файле (в превью — CSS-приближение)
- Шторка — «надвиг», а не маска-вытеснение (Media3 compositor не поддерживает маски без своего шейдера)
- При наплыве/шторке звук соседних клипов на стыке просто смешивается (без плавной кривой)
- Если хоть у одного клипа нет звука, исходный звук отключается у всех
- Без наложения кадров текст накладывается на каждый клип; с наложением — один раз на итоговое видео
- Самые рискованные места для проверки на устройстве: двухдорожечный экспорт (наплыв/шторка), скорость + звук

## Структура
- `index.html`, `styles.css`, `app.js` — UI; копируются в `www/`
- `android/app/src/main/java/com/clipmaster/app/VideoEnginePlugin.java` — импорт/экспорт; `Fx.java` — фильтры и покадровые переходы
- `store/` — иконка 512, баннер 1024×500, `privacy.html`, `LISTING-RU.md`, `make_assets.py` (генерирует иконки лаунчера и сплэш)
- `release/` — keystore и пароли (в .gitignore, хранить в резервной копии!)
